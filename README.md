# DataDesk

> **Manage. Analyze. Decide.**

DataDesk is a full-stack management and analytics platform designed to help organizations manage employees, projects, tasks, and budgets through a centralized dashboard.

The project focuses on **relational database design, SQL-driven analytics, and full-stack development**.

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **Charts:** Recharts
* **API:** REST

## ✨ Planned Features

* Employee management
* Department management
* Project management
* Task tracking
* Budget management
* Analytics dashboard
* SQL-powered business insights

## 🗄️ Database

DataDesk uses a relational MySQL database with interconnected entities for employees, departments, projects, tasks, and budgets.

The database design will demonstrate:

* Relational database design
* Primary and foreign keys
* Constraints
* Joins
* Aggregations
* Subqueries
* CTEs
* Window functions
* Transactions
* Indexing
